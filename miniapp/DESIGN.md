# DESIGN.md — 拍照批改作业小程序设计系统（Claude 暖色 ×「微光」玻璃拟态）

> 品牌基色来自 **Claude（Anthropic）**（parchment + terracotta + editorial serif）；
> 卡片层采用**「微光」玻璃拟态**（Glassmorphism）：半透明 pastel 玻璃卡浮在粉彩光斑画布上，
> 磨砂 blur 20px + 顶部高光 + 柔和投影，微旋转，像被随手贴上去的便签。
> Taro 跨端（weapp/H5），单位为设计稿 px（750 基准）。

## 1. Visual Theme & Atmosphere

- **羊皮纸 + 粉彩光斑**：页面底是羊皮纸 `#f5f4ed`，其上铺薄荷/蜜桃/雾蓝/樱粉四团 radial 光斑——玻璃卡的 blur 才有内容可磨。
- **玻璃卡六要素**：半透明 pastel 面 + `backdrop blur 20px saturate(1.3)` + 白色半透明描边 `rgba(255,255,255,0.9)` + 顶部高光 `inset 0 1px 0 rgba(255,255,255,0.85)` + 柔和投影 + 大圆角。
- **微旋转**：装饰性大卡 ±0.6°（资产卡 -0.6°、横幅 +0.6°）；列表行不转，保可读性。
- **字阶靠透明度分层**：正文暖黑 100%，说明文字 62%（如 `rgba(20,20,19,0.62)`），不靠字号堆叠。
- **衬线标题 = 书名**：宋体衬线（对应 Anthropic Serif）只给标题与大数字，字重 ≤600。
- **赤陶做唯一彩色锚点**：实色只留给主按钮与打卡勾；大面积彩色一律走 pastel 玻璃。
- **语义色独立于主色**（沿袭不变）：错=深红 `#b53333`，对=哑绿 `#4e7a40`，待核对=琥珀 `#b07818`。

## 2. Color Palette & Roles

### Primary
- **赤陶 `#c96442`**：主按钮、大数字、品牌时刻；按下 `#b0563a`
- **蜜桃深字 `#8a4630`**：蜜桃玻璃上的文字（横幅主文案 100% / 说明 62%）

### Surface（玻璃面 = 半透明 pastel，压在光斑画布上）
| 玻璃面 | 色值 | 用途 |
|--------|------|------|
| 纯白玻璃 | `rgba(255,255,255,0.62)` | 默认卡、按钮、胶囊；按面 0.8 |
| 薄荷玻璃 | `rgba(221,245,232,0.62)` | 资产卡（积分=成长） |
| 蜜桃玻璃 | `rgba(255,224,205,0.72)` | 行动横幅 |
| 雾蓝玻璃 | `rgba(228,236,252,0.55)` | 任务快览 |
| 羊皮纸玻璃 | `rgba(245,244,237,0.6)` | 完成态、输入框底 |
| 樱粉/薰衣草紫/青瓷 | `#fde5ec` / `#ece7fb` / `#e2f0ea` | 备用点缀（不与前三者同屏多用） |

### Text（透明度分层）
- 暖黑 `#141413`（100%）→ 说明 `rgba(20,20,19,0.62)` → 弱化 `rgba(20,20,19,0.45)` 或石灰 `#87867f`
- 薄荷底上的文字：`rgba(47,92,70,0.62)`；蜜桃底上：`rgba(138,70,48,0.62)`

### Semantic
- 错/扣分：深红 `#b53333`，底 `#f6e7e4`
- 对/掌握：哑绿 `#4e7a40`，底 `#e7efe2`
- 待核对/进行中：琥珀 `#b07818`，底 `#f2ecdc`

## 3. Typography Rules

- **标题/大数字（衬线）**：`"Songti SC", "STSong", "Noto Serif SC", Georgia, serif`，字重 ≤600，行高 1.05~1.3
- **正文/UI（无衬线）**：`-apple-system, "PingFang SC", sans-serif`，行高 1.6
- 等宽只给代码；层级靠透明度与字重（400/500/600），不靠字号堆叠

| 角色 | 字体 | 字号 | 字重 |
|------|------|------|------|
| Hero 标题 | 衬线 | 56px | 600 |
| Display 数字 | 衬线 | 96px | 600 |
| 区块标题 | 衬线 | 32px | 600 |
| 横幅主文案 | 衬线 | 42px | 600 |
| 正文 | 无衬线 | 28px | 400 |
| 说明文字 | 无衬线 | 22-24px | 400，透明度 62% |

## 4. Component Stylings

### Buttons
- **Primary**：赤陶实底 `#c96442` + 象牙字 + 白描边 `rgba(255,255,255,0.55)` + 顶部高光 + `0 8px 24px rgba(201,100,66,0.35)`，radius 32；全页唯一实色彩色按钮。
- **Ghost**：纯白玻璃（0.62）+ 白描边 + blur，radius 32。
- 按下：`scale(0.97)`，0.18s ease。

### Glass Cards（核心令牌）
```
background: rgba(255,255,255,0.62);        /* 或对应 pastel 面 */
border: 1px solid rgba(255,255,255,0.9);
border-radius: 46px;                       /* 主卡=23css px；紧凑行 32 */
backdrop-filter: blur(20px) saturate(1.3);
box-shadow: inset 0 1px 0 rgba(255,255,255,0.85), 0 8px 32px rgba(20,20,19,0.08);
```
- 特色卡（资产/横幅）附加微旋转 ±0.6° 与更强的色系投影。
- 按下：面浓度 +0.18（如 0.62→0.8）+ `scale(0.98)`。
- weapp 端 `backdrop-filter` 渐进增强：不支持时半透明 pastel 面依旧成立。

### Badges / Pills
- 状态胶囊 999px、22px/600、语义浅底实色（可读性优先，不做玻璃）。

### Inputs
- 羊皮纸玻璃底 `rgba(245,244,237,0.6)` + 暖沙边，radius 32；聚焦边框赤陶。

## 5. Layout Principles

- 基础 8px；卡片间 24px、区块间 36px。
- 首页看板顺序不变：Hero → 薄荷资产卡 → 雾蓝任务快览 → 蜜桃横幅 → 白玻璃批改列表。
- 微旋转让卡片「随手贴上去」：每屏最多 2 张旋转卡。

## 6. Depth & Elevation

| 层级 | 处理 | 用途 |
|------|------|------|
| 0 光斑画布 | 多层 radial pastel + `#f5f4ed` | 页面底 |
| 1 玻璃面 | 半透明 pastel + 白描边 | 所有卡 |
| 2 磨砂 | `blur(20px) saturate(1.3)` | 主要容器 |
| 3 顶部高光 | `inset 0 1px 0 rgba(255,255,255,0.85)` | 全部玻璃面 |
| 4 柔和投影 | `0 8~12px 24~32px rgba(20,20,19,0.05~0.08)` | 主卡 |

禁止：重投影、实色大底卡、冷灰描边、彩边框（语义胶囊除外）。

## 6.1 过渡与兼容

- weapp：`backdrop-filter` 在 iOS WKWebView 与 Android XWeb 可用，低版本退化为纯半透明面（视觉可接受）。
- H5：Safari/Chrome 均支持。

## 7. Do's and Don'ts

### Do
- 玻璃面必须配白描边 + 顶部高光，缺一就不是「微光」
- 新卡片先问用哪个 pastel 面（默认纯白玻璃）
- 微旋转只给每屏 1-2 张装饰性大卡
- 说明文字用 62% 透明度分层
- 大数字/标题衬线 ≤600 字重

### Don't
- 不要在玻璃上再叠玻璃描述性边框/重阴影
- 不要把语义胶囊也做成玻璃（可读性优先）
- 不要引入饱和实色大底（赤陶按钮除外）
- 不要用冷灰/纯黑描边
- 不要给列表行加旋转

## 8. Responsive Behavior

- 750 设计稿基准，Taro 自动缩放；触控目标 ≥ 88px；最小字号 22px。
- H5 内容最大宽 750px 居中；`body` 背景同羊皮纸。
